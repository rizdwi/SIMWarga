Proyek

SIMWarga (Sistem Manajemen Warga)

Aplikasi Android Native

Aplikasi untuk mengelola data identitas warga (KK dan NIK) di tingkat RT/RW. Dirancang untuk bekerja sepenuhnya tanpa koneksi internet (offline-first). Memiliki fitur impor dan ekspor data ke format Excel (.xlsx) serta keamanan akses menggunakan PIN yang dilindungi algoritma SHA-256.

Pencapaian Teknis:

Membangun modul pembaca dan penulis file OpenXML dari awal menggunakan Java standar tanpa dependensi berat seperti Apache POI, sehingga ukuran akhir aplikasi hanya 6.4 MB.

Kotlin Room DB MVVM Material Design 3
Repositori SIMWarga

SelarasKas (Manajemen Keuangan)

Aplikasi Web Fullstack

Sistem pencatatan keuangan pribadi untuk melacak pemasukan dan pengeluaran harian. Menyediakan dasbor analitik visual berbasis grafik, fitur pelacakan target tabungan, dan struktur basis data yang mendukung akses multi-pengguna.

Pencapaian Teknis:

Menerapkan pola desain Model-View-Controller (MVC) yang bersih terpadu dengan desain basis data relasional yang dinormalisasi dengan baik.

Laravel PHP JavaScript MySQL
Repositori SelarasKas

BookLapang (Booking Lapangan)

Aplikasi Web Fullstack

Sistem reservasi lapangan olahraga dengan manajemen peran pengguna ganda (admin dan pelanggan). Dilengkapi halaman administrasi untuk pemantauan pendapatan serta manajemen operasional lapangan dan jadwal secara penuh.

Pencapaian Teknis:

Mencegah masalah pemesanan ganda (double booking) dengan mengimplementasikan validasi jadwal yang ketat dan menggunakan fitur transaksi bawaan basis data.

Teknologi:

  • • Laravel 11
  • • Blade Templates
  • • Tailwind CSS
  • • SQLite
